# Supply-chain-Performance-Risk-Analytics-Dashboard

## Project Overview

This project analyzes supply chain operations using Python, SQL, and Power BI.

The objective is to identify supplier performance trends, inventory risks, logistics bottlenecks, and procurement cost drivers.

---

## Tools Used

- Python
- Pandas
- NumPy
- SQL
- Power BI
- DAX

---

## Project Workflow

1. Data Cleaning using Python
2. Exploratory Data Analysis (EDA)
3. SQL Business Analysis
4. Power BI Dashboard Development
5. Business Insights & Recommendations

## Key Insights

- Alpha Logistics achieved the highest fill rate.
- Nexus SCM processed the highest order volume.
- Eastern Traders recorded the highest lead time.
- Packaging products accounted for the highest inventory levels.
- Inventory risks were identified across multiple warehouses.
